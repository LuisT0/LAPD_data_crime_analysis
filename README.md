## 📖 Project Overview

This project presents an **Exploratory Data Analysis (EDA)** of crime records from Los Angeles, California. The objective is to hypothetically assist the Los Angeles Police Department (LAPD) by identifying **spatial and temporal patterns** in criminal behavior.

The insights from this analysis could be used to optimize resource allocation, design preventive strategies, and ultimately enhance public safety across the city's diverse neighborhoods.

## ✨ Analysis Phases

The Jupyter Notebook guides you through the entire investigative process:

*   **Data Cleaning & Preparation:** Processing the `crimes.csv` dataset to efficiently handle timestamps, and categorical data.
*   **Exploratory Analysis (EDA):** Investigating the distributions of crime types, and identifying peak hours and days for criminal incidents.
*   **Geospatial Analysis:** Creating heatmaps and other geographic visualizations to pinpoint crime "hotspots" across the city.
*   **Temporal Analysis:** Developing time-series plots to detect trends, seasonality, and other patterns over time (by hour, day of the week, month).
*   **Actionable Insights:** Summarizing the key findings that could inform strategic decisions for the LAPD.

## ⚙️ Installation & Usage

1.  **Clone the repository:**
    ```
    git clone https://github.com/YOUR_USER/LAPD-Crime-Analysis.git
    cd LAPD-Crime-Analysis
    ```
2.  **Create and activate a virtual environment:**
    ```
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```
3.  **Install the dependencies:**
    ```
    pip install -r requirements.txt # Make sure to create this file
    ```
4.  **Launch Jupyter Notebook:**
    ```
    jupyter notebook
    ```
    Then open `notebooks/project analyzing crime in Los Angeles.ipynb` to explore the analysis.
